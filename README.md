## Factorial Program in C#

This program calculates the factorial of a given non-negative integer. The factorial of a number `n` (denoted as `n!`) is the product of all positive integers less than or equal to `n`.

### Example
For instance:
- Input: `5`
- Output: `120` (calculated as `5 * 4 * 3 * 2 * 1`)

### Implementation Overview
The program uses either a recursive or iterative approach to compute the factorial.

### Steps
1. **Input**: Accept a non-negative integer from the user.
2. **Validation**: Ensure the input is a valid non-negative integer.
3. **Calculation**: Compute the factorial using recursion or iteration.
4. **Output**: Display the calculated factorial to the user.

### Notes
- The factorial of `0` is defined as `1` (`0! = 1`).
- Large input values may result in integer overflow if not handled properly.

### Usage
To calculate the factorial of a number:
1. Run the program.
2. Enter a non-negative integer when prompted.
3. View the calculated factorial displayed as output.
